# Pitfall: pen-test harness scored backend failures as PASS — a gate that reads agent output must first prove the agent ran

## Summary
Pen-test harness false-success (PR#5795, 2026-10-22): tests/pentest runOne returned ERROR only on a nil result, but a backend failure returns a result with Success=false, so eight runs that died in ~2s (claude exit 1, 4 events) scored PASS on empty outputs — identical evidence lines on every row were the tell. Rule for any harness or gate that reads agent output: require proof of execution (an assistant turn, a tool call, a non-empty result) before asserting absence of bad things; a probe that exists to exercise a guard is ERROR when nothing exercised it. Third instance of the TASK-460 class.
