# Pitfall: effort classifier 429s on the box are OAuth-token noise, not a rate limit — direct mode only disables on 401

## Summary
Effort classifier 429 noise (2026-10-22): internal/executor/effort_classifier.go picks the first of PILOT_CLASSIFIER_API_KEY, ANTHROPIC_API_KEY, ANTHROPIC_AUTH_TOKEN, CLAUDE_CODE_OAUTH_TOKEN; the box has only the OAuth token, so every direct Messages API call returns 429 {message:Error} (23/23 today) and falls back to the subprocess (~5 s per task). Direct mode is disabled only on 401 (GH-5344). These 429s are not an account rate limit and do not correlate with concurrency; do not read them as pool exhaustion. Fix: pilot#5802.
