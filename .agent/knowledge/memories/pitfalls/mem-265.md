# Pitfall: daily_ticket_cap enforced twice — reconciler (ledger, UTC, platform key, box stop) vs board gate (ticket_dispatches, org tz, any key, 429); board gate misses four dispatch paths

## Summary
Pilot Cloud daily_ticket_cap (default 15) was enforced twice with different counters (found 2026-10-22, PR#425 review D1): the fleet reconciler enforceDailyTicketCap counts succeeded platform-key tickets from the ledger per UTC day and switches the key or stops the EC2 box (~1h lag, off unless PILOT_CONSOLE_ALLOWANCE_ENFORCE_ENABLED); the board gate AdmitDispatch counts admitted board dispatches per org-local day on any key and returns 429. The board gate never sees direct tracker labels, chat tasks, epic sub-issues or autopilot fix issues. Rule: a cap knob has exactly one enforcer; put it where every path funnels (ExecutionLifecycle.Begin on the daemon). TASK-589.
