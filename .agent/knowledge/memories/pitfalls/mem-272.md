# Pitfall: non-Go merge conflicts hold the PR until a human pushes — chain sibling legs that share files

## Summary
Non-Go merge conflicts are a hard hold (2026-10-22): autopilot's mechanical conflict resolution covers go.mod/go.sum only; a conflict in any other file sets RebaseHoldActive + needs-manual-rebase + pilot-needs-human and waits for a pushed head SHA. ui PR#253 conflicted with the sibling epic (ui#240 → PRs 250-252) on six Vue/TS files. Recovery: close the PR, delete the branch, strip the three labels, cycle pilot so the task re-runs from fresh main. Sibling legs that touch the same files should be chained with Blocked by, not filed in parallel.
