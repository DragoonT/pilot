# Pitfall: A daemon-posted GitHub review cannot hold an autopilot merge: isTrustedReviewer drops bot and own-login reviews by design (GH-5326), and the client has no change-request review call

## Summary
Placement B for an automated reviewer (post a REQUEST_CHANGES review at ci_passed and let the existing changes-requested hold stop the merge) does not work: internal/autopilot/controller.go isTrustedReviewer (~5000) returns false for logins containing [bot], ending in -bot, or equal to the cached authenticated login, so the daemon's own review is ignored by both the merge hold (handleMerging ~5687) and the webhook path; the GitHub client only has ApprovePullRequest (REQUEST_CHANGES constant unused); GitHub also returns 422 on self-review of one's own PR (mem-204). The existing review-fix path (handleReviewRequested) closes the PR and files a fix issue on the same branch: a new 25-45 min cycle, not an in-place fix.

## Recommended Approach
