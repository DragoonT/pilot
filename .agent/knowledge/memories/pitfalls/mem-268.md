# Pitfall: shared pilot_test_<pkg> databases on the box collide across worktrees — 'no migration found for version N'

## Summary
Shared test databases collide across worktrees (2026-10-22): pilot-console tests use persistent per-package databases pilot_test_<pkg> on the box's shared Postgres (internal/testdb/testdb.go const Prefix). GH-424's gate applied migration 0033; GH-423's worktree on an older base then failed 3 gates with 'no migration found for version 33', auto-preserved and stalled. Any two sibling tasks with different migration sets collide. Fix: per-run prefix PILOT_CONSOLE_TESTDB_PREFIX (console#428) in the box gate command.
