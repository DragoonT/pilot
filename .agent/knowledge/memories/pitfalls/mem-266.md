# Pitfall: pack draw read ticket_dispatches (board only, counted at admission) while the billing meter reads the ledger — any billing draw must read the ledger

## Summary
Pack draw on the wrong counter (PR#425, 2026-10-22): AdmitDispatch counts plan tickets used from ticket_dispatches (board dispatches only, counted at admission even if the run fails, own-key rows included) while the allowance meter counts succeeded executions from the ticket ledger. On direct-label, epic, chat and autopilot paths packs draw late or never, and the two meters diverge. Rule: any billing draw reads the ledger (execution-level, deduplicated by task id, the documented billing source in fleet/usage_meter.go), never a dispatch-side side table. TASK-589 moves the draw to ledger ingest.
