# Pattern: probe: lines in LEG bodies pin the premise against origin/main before filing

## Summary
Probe lines pin a leg's premise (added 2026-10-22, commit after 7dc8c993b): inside a ### LEG body, 'probe: present|absent owner/repo <regex>' lines are checked by scripts/nav-dispatch-legs.py pre-flight with git grep -E on that repo's origin/main and stripped from the filed body.
