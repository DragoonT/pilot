# Pattern: the CI-fix size guard parks a big PR at StageFailed with no revive on a green rerun

## Summary
CI-fix size guard parks big PRs for good (2026-10-22): when a tracked PR's CI goes red and the PR has more production additions than max_ci_fix_pr_size (200), controller.go escalateAndHold('CI fix size guard fired') sets StageFailed + pilot-needs-human and spawns no fix issue, even for a flaky unrelated test (console PR#426, 407 additions). Nothing revives it when a rerun goes green on the same SHA; the only redrives are reAdoptHeldRebasePR and redriveFailedPRForBaseRetarget. Recovery today: review + hand squash-merge + label cleanup. Fix: pilot#5801.
